# Assets

## social-preview.png

The repository's social preview card, 1280 by 640, as uploaded in
**Settings → General → Social preview**.

It is kept here because GitHub stores an uploaded preview on its own CDN and
offers no way to read it back. Without a copy in the repository there would be
no record of what was uploaded, and no source to work from when the card needs
changing.

Re-uploading is manual. GitHub exposes no API for the social preview.
